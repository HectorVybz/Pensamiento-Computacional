# Pensamiento-Computacional
Hola mi nombre es Hector, mi matricula es A01713794 y voy a hacer una lista virtual de supermercado para ayudar a encontrar y organizar los artículos de las personas mas eficientemente, me parece interesante porque nos enseña el uso de codigos para crear programas de nuestra preferencia, me parece util por el hecho de que al querer ingresar a un trabajo, estos ejercicios nos ayudaran a estar preparados y nos ayudaran a tener una idea de como funciona el crear un programa.

Entrada:
  Producto (string)
  Precio (float)
  Cantidad (integer)
  Eleccion del menu (integer)
Salida:
  Total de productos
  Total a pagar

Proceso:
  Ingresa el producto 
  Ingresa el precio del producto seleccionado
  Ingresa la cantidad de productos similares
  Se muestra el total de productos que se van a comprar o si se elimina alguno
  Se muestra el total a pagar
  Se cierra el programa
